Widget 5: Fixed-ERF Threshold Explorer

The data are generated by an adjacent-category model whose threshold structure you choose, constrained to have exactly the binomial’s expected response function. Compare it with the binomial that has that same ERF: only the way probability is spread across categories differs.

Roles. Data-generating model (solid curves): the adjacent-category model with your step structure τ. Approximating model (dashed): the binomial with the same ERF. The fixed ERF is the expected-score curve both share; it is not itself a model that generates data.

Try this: move the s slider. The ERF panel does not change at all, but the data-generating model’s category curves (solid) pull away from the binomial’s (dashed), and the KL readout grows. Click Binomial spacing and the data-generating model becomes the binomial itself.

How it works. The model is adjacent-category (GPCM-type): log{P(X=k|θ)/P(X=k−1|θ)} = η(θ) − τk. The step offsets τk set the threshold structure. η(θ) is the link: the part of every adjacent-category log-odds that depends on ability. For a GPCM, η(θ) = aθ and τk = a·bk, giving the usual steps a(θ − bk); for the binomial, η(θ) = logit f(θ) and τk = log{k/(K−k)}. Category k overtakes k−1 where η(θ) crosses τk. For any choice of τ, η(θ) is solved at each θ so that E[X|θ] equals the fixed ERF exactly (expected score is strictly increasing in η, so the solution is unique). With τk = log{k/(K−k)}, η(θ) = a(θ − b) is linear and the model is the binomial. With any other τ, η(θ) generally bends, so the data-generating model is GPCM-like but not a strict GPCM (which has linear η); the “η(θ) departure from linear” readout says how far it is from one. Adding a constant to every τk only shifts η(θ), so only the gaps between offsets matter. To compare whole models (binomial, GPCM, GRM) that share an ERF, see Same ERF, different models.

KL is the expected log-loss penalty for predicting categories with the binomial when the data-generating model produces the data. Because the binomial has the same ERF, this is purely the structural term of the manuscript’s KL decomposition: the category-level loss that an ERF criterion such as RMSE cannot see. The ERF deviation is numerical error only.
