Widget 5: Fixed-ERF Threshold Explorer

Hold the expected response function fixed and change the threshold structure. Every configuration has exactly the same ERF as the binomial target; only the way probability is spread across categories changes.

Try this: move the s slider. The ERF panel does not change at all, but the category curves (solid) pull away from the binomial’s (dashed), and the KL readout grows. Click Binomial spacing to bring them back together.

How it works. The model is adjacent-category (GPCM-type): P(X=k|θ) ∝ exp(Σj≤k(η(θ) − δj)). The step offsets δk set the threshold structure; η(θ) is the link. For any choice of δ, η(θ) is solved at each θ so that E[X|θ] equals the target ERF exactly (expected score is strictly increasing in η, so the solution is unique). With δk = log{k/(K−k)}, η(θ) = a(θ − b) is linear and the model is the binomial. With any other δ, η(θ) generally bends, so a strict GPCM (linear η) can only approximate this ERF. Adding a constant to every δk only shifts η(θ), so only the gaps between offsets matter. To compare whole models (binomial, GPCM, GRM) that share an ERF, see Same ERF, different models.
