Widget 6: Category Loss and KL Decomposition

Compare a GPCM item with two binomial approximations: the mean-matched binomial, which reproduces the GPCM’s ERF exactly, and the best-fitting logistic Binom 2PL. See where the binomial’s category-level loss falls and how much of it any link function could remove.

Try this: with the defaults, the structural share in the bottom-right panel is about 90%: most of the Binom 2PL’s loss remains even when the mean is exactly right. Set K = 6, s = 2.1, a = 2 to get about 86%, then lower a to 1 and watch it fall to about 80%. Move θ to see which categories carry the loss; near θ ≈ −2.5 the Binom 2PL’s bars (blue) pull away from the mean-matched binomial’s (red), because there it gets the mean wrong.

How it works

The mean-matched binomial (the oracle of the manuscript’s KL decomposition) uses f*(θ) = E[X|θ]/(K−1) from the true GPCM, so its ERF is identical to the GPCM’s. The Binom 2PL uses f(θ) = logistic(a′(θ − b′)), with a′ and b′ chosen to minimize expected KL divergence from the GPCM over θ ~ N(0,1).

The Binom 2PL’s KL divergence from the GPCM splits exactly into a structural term, KL(GPCM ‖ mean-matched binomial), which no link function can remove, and a link term, (K−1)·KL{Bern(f*) ‖ Bern(f)}, the extra loss from getting the mean wrong. The table reports both at the chosen θ and averaged over θ ~ N(0,1), using the same θ grid and fitting criterion as the manuscript (kl_decomposition.R), for a single item with no threshold noise. The manuscript’s table averages over 200 random items with threshold noise, so a single item here can sit above or below it.

GPCM thresholds follow the simulation design: total span 3, gaps ∝ exp(s·j/(K−3)), so the max/min gap ratio is e|s| and s = 0 is equal spacing.
